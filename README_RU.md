# VPN-ТРЭШ! — стартовый Android-проект

Это **демо-интерфейс**, а не работающий VPN. Кнопка подключения меняет только состояние экрана. VPN-трафик не шифруется и не перенаправляется.

## Что уже есть
- Kotlin + Jetpack Compose
- Минималистичный тёмный интерфейс с зелёными акцентами
- Экран выбора страны
- Простой экран профиля
- Заглушки WireGuard и Premium

## Как собрать APK
Полноценная сборка Android-проекта обычно требует Android SDK и JDK. Наиболее надёжный путь — открыть папку проекта в Android Studio на компьютере. Если доступен только телефон, можно попробовать совместимую Android IDE, но поддержка Gradle/Compose зависит от приложения и устройства.

1. Установите Android Studio с официального сайта https://developer.android.com/studio
2. Откройте эту папку как существующий проект.
3. Дождитесь синхронизации Gradle.
4. Выберите Build > Build APK(s).
5. Установочный APK обычно появляется в `app/build/outputs/apk/debug/app-debug.apk`.

## Следующий этап: реальный WireGuard
Не включайте кнопку в настоящий режим, пока не настроены:
- VPN-провайдер или ваш WireGuard-сервер;
- законное разрешение на коммерческую перепродажу/использование в собственном клиенте;
- безопасная выдача отдельной конфигурации каждому пользователю;
- интеграция официальной WireGuard Tunnel Library и Android VPN permission flow;
- обработка отключения, ошибок, DNS и потери сети.

Официальная документация:
- https://www.wireguard.com/
- https://www.wireguard.com/embedding/
- https://developer.android.com/develop/connectivity/vpn

## Безопасность
- Не встраивайте общий приватный ключ в APK.
- Не присылайте приватные ключи в чат.
- Используйте HTTPS для API.
- Указывайте в интерфейсе честный статус соединения.
- Не называйте демо-переключатель реальным подключением.


## Сборка APK через GitHub Actions с телефона

В проект добавлен workflow `.github/workflows/build.yml`.

1. Загрузите содержимое проекта в новый GitHub-репозиторий.
2. Откройте вкладку **Actions** в репозитории.
3. Выберите **Build Android APK**.
4. Нажмите **Run workflow** (если кнопка доступна) или сделайте commit в ветку `main`/`master`.
5. После завершения успешного запуска откройте запуск workflow и скачайте artifact **VPN-TRESH-debug-apk**.
6. Распакуйте скачанный artifact — внутри будет APK для тестовой установки.

Это debug APK для тестирования. Интерфейс приложения сам по себе не создаёт реальное VPN-подключение; для этого отдельно требуется интеграция WireGuard и доступ к VPN-серверам/провайдеру.
